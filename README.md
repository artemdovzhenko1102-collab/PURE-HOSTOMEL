# PURE beauty room: сайт и админка для Netlify

- **Сайт:** главная страница `/`.
- **Админка:** `/admin`. Роли «админ» и «мастер».
- **Сервер:** Netlify Functions (`netlify/functions/api.mjs`).
- **База и загруженные фото:** Netlify Blobs. Отдельная база данных не нужна, на бесплатном тарифе всё работает.

## Как залить на Netlify

### Самый быстрый способ: перетащить ZIP

1. Откройте https://app.netlify.com/drop (можно сразу войти в аккаунт).
2. Перетащите туда этот ZIP или распакованную папку. Netlify найдёт `package.json`, сам установит зависимости и соберёт функции.
3. Откройте `https://ВАШ-САЙТ.netlify.app/admin` и войдите:
   - логин: **admin**
   - стартовый пароль: **Pure-t8kMnqAM**
4. **Сразу смените пароль:** «Змінити пароль» внизу меню.

Свой пароль админа можно задать и заранее: Project configuration → Environment variables → `ADMIN_PASSWORD`. Это работает только до первого входа, потом пароль меняется в админке.

Если после деплоя запись или админка не работают (ошибка 404 на `/api/...`), используйте способ через GitHub ниже. Он надёжнее всего.

### Через GitHub (обновления потом будут подтягиваться автоматически)

1. Создайте репозиторий на github.com и загрузите в него всё содержимое папки, кроме `node_modules`.
2. В Netlify выберите Add new project → Import an existing project → GitHub → этот репозиторий. Настройки подтянутся из `netlify.toml`.
3. Нажмите Deploy и войдите в `/admin` с тем же стартовым паролем.

### После первого входа

- **Доступи:** создайте логины мастерам и привяжите каждого к мастеру на сайте.
- **Графік:** каждый мастер в разделе «Мій графік» задаёт рабочие дни и часы, длительность записи и на сколько дней вперёд можно записываться. В календаре можно отметить отдельный день выходным или поставить на него особые часы. Админ видит графики всех мастеров («Графіки майстрів»). Пока график не сохранён, действует стандартный: пн–пт 9:00–19:00, сб 10:00–17:00.
- **Налаштування:** контакты, график салона, Telegram-уведомления.

### Как работает запись

- Клиент выбирает мастера и видит только свободные дни и время.
- Занятое время (новые и принятые заявки) скрывается автоматически.
- Записаться на прошедшее время или раньше чем за час нельзя.
- Если два клиента выберут один и тот же слот, второму сайт предложит выбрать другое время.
- Если клиент выбрал «будь-який майстер», показывается время, когда свободен хотя бы один мастер.

## Альтернатива: Netlify CLI

```bash
npm install
npm install -g netlify-cli
netlify login
netlify init        # создать или привязать сайт
netlify env:set ADMIN_PASSWORD 'ваш_пароль'
netlify deploy --prod
```

Просто перетащить папку в Netlify Drop не получится: при таком способе серверные функции не собираются, и запись и админка работать не будут.

## Структура

```
public/              статический сайт: index.html, admin.html, img/, uploads/seed-*.jpg (стартовые фото)
netlify/functions/   api.mjs → /api/*, uploads.mjs → /uploads/* (фото, загруженные через админку)
netlify/lib/         общая логика (core.mjs), графики и слоты (schedule.mjs), стартовые данные (seed.mjs)
netlify.toml         настройки Netlify
```
